# Dr. Maya Reynolds — Therapy Website

A responsive therapist website created as part of a Front-End Developer Internship assignment.

## Live Demo

https://maya-therapy-site-nine.vercel.app/

## Project Overview

This project presents a professional website for Dr. Maya Reynolds, PsyD, a fictional clinical psychologist based in Santa Monica, California. It introduces therapy services, treatment approaches, and the office environment.

## Features

* Responsive desktop and mobile layout
* Therapist introduction and profile
* Therapy services for anxiety, panic, trauma, burnout, and perfectionism
* Therapeutic approach and treatment information
* Office gallery with images
* Contact section
* Image optimization using Next.js Image

## Tech Stack

* Next.js
* React
* TypeScript
* Tailwind CSS

## Getting Started

Clone the repository and install dependencies:

```bash
git clone https://github.com/divyajyotisingh21-netizen/maya-therapy-site.git
cd maya-therapy-site
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## Deployment

Deployed using Vercel.
